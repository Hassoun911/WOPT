## Important architecture facts

- Android phone, iOS, tablet and TV share much of the Expo/React Native code under `mobile/`.
- Tablet and TV both use the Masjid/display renderer, so changes to `MasjidDisplayPage.tsx` can affect both.
- Wear OS is a separate native Gradle project under `wearos/`.
- iOS configuration is committed in `mobile/app.config.ts` and `mobile/eas.json`; a permanent native `mobile/ios/` directory is not currently committed and is generated by Expo/EAS when required.

## Rule

Do **not** choose a branch, old version-numbered workflow, or old patch by memory. Always:

1. Start on `main`.
2. Open this file.
3. Route to the correct platform README above.
4. Inspect that platform's source/workflow before making changes.
5. Treat old release/build branches as history or rollback unless explicitly requested.
