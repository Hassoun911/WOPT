1. Version number
2. Exact APK filename
3. Branch/ref used

6. Approx. APK size
7. Key changes included
8. Install/test status reported by the user
9. Mark the newest record clearly as **Last APK issued**

Do not infer the APK version from a branch name alone. Match the APK filename/version to the actual build record whenever possible.
